# Основной пользовательский сценарий

1. Пользователь открывает навигатор.
2. Система показывает доступные точки кампуса.
3. Пользователь выбирает начальную и конечную точки.
4. Пользователь указывает временно недоступные точки, если они есть.
5. Система проверяет введенные данные.
6. Система выполняет поиск в ширину.
7. Пользователь получает маршрут по шагам.

## Альтернативные ситуации

- Если одна из точек не существует, система сообщает об ошибке.
- Если начальная и конечная точки совпадают, маршрут не строится.
- Если лифт закрыт, система ищет маршрут через лестницу.
- Если все пути закрыты, система сообщает, что маршрут не найден.
