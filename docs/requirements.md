# Исходные требования

1. Пользователь выбирает начальную и конечную точки внутри кампуса.
2. Система проверяет существование выбранных точек.
3. Система строит маршрут по учебному графу кампуса.
4. Результат содержит последовательность точек от начала до конца.
5. При невозможности построения маршрута выводится понятное сообщение.
6. Администратор может изменять состав точек и переходов графа.

## Уточненное требование ЛР № 2

Система должна исключать временно недоступные точки из поиска. Если основной переход закрыт, но существует другой путь, строится альтернативный маршрут. Если альтернативного пути нет, возвращается сообщение об отсутствии маршрута.
