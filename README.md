# Навигатор кампуса «Нагатинская»

Учебный проект для лабораторной работы № 2 по дисциплине «Современные технологии разработки программного обеспечения».

Проект демонстрирует поиск маршрута внутри восьмиэтажного здания кампуса. Здание представлено невзвешенным неориентированным графом, а маршрут строится алгоритмом поиска в ширину (BFS). В обновленной версии поиск исключает временно недоступные точки, например закрытый лифт, и находит обходной путь через лестницу.

## Требования

- Java 20;
- стандартная библиотека Java;
- сторонние зависимости не используются.

## Запуск

```bash
javac --release 20 -d out src/ru/synergy/campus/*.java
java -cp out ru.synergy.campus.Main
java -cp out ru.synergy.campus.RouteFinderTest
```
